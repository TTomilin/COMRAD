# `results/`

This directory stores committed artifacts derived from benchmark runs and from the studies in
[`../experiments/`](../experiments/README.md). The code that produces them lives in [`../scripts/`](../scripts/README.md)
(main benchmark) and `../experiments/` (additional studies). The headline figures are on the
[baselines page](https://ttomilin.github.io/COMRAD/baselines/). Web-sized copies live in `docs/assets/` and are
regenerated by `scripts/build_docs_assets.sh`.

## Top-level files

- paper-ready figures such as `baseline_learning_curves.*`, `baseline_results_heatmap.*`, `agent_scaling_*.*` and
  `curriculum_protocol_*.*`
- scenario and taxonomy figures such as `scenario_overview.png`, `categories*.png` and `difficulty_axes*.png`
- summary JSON and generated LaTeX rows of the Very Difficult study (`very_difficult_*`)

## Benchmark subdirectories

| Folder | Contents | Script |
|---|---|---|
| `scaling/` | TensorBoard event files of the Armory Siege agent-scaling runs (2, 3, 4, 6, 8 agents) | read by `scripts/agent_scaling_figure.py` |
| `scenarios/` | scenario overview images | read by `scripts/build_docs_assets.sh` |
| `appendix_scenario/` | per-scenario images for the paper appendix | none |
| `variants/` | generated WAD variants plus rendered previews | written by `scripts/make_doomgen_variants*.py`, `scripts/render_doomgen_variant_images*.py` |
| `videos/` | rendered trajectory and heatmap media | written by `scripts/record_ammo_carrier_nav_heatmaps.sh` |
| `demo_all_checkpoints/` | demo video and GIF for the docs | written by `scripts/record_demo_all_checkpoints.sh` |

## Study subdirectories

| Folder | Study |
|---|---|
| `heldout_very_difficult/`, `very_difficult_eval/` | held-out evaluations of the Very Difficult references ([`very_difficult/`](../experiments/very_difficult/README.md)) |
| `scripted_partner_videos/` | per-episode JSON logs of the scripted-partner recordings ([`very_difficult/`](../experiments/very_difficult/README.md)); the mp4 videos are not committed |
| `rebuttal_kd6j/`, `rebuttal_c2k6/`, `difficulty_grid/` | ICLR 2027 rebuttal studies ([`iclr2027_rebuttal/`](../experiments/iclr2027_rebuttal/README.md)) |

## Evaluation inputs

These folders hold fixed WAD batches that the evaluations read, not outputs:

- `heldout_wad_batches/`: the held-out layouts (seeds 1009, 2027, 3037, 4051, 5099) with their `batch_registry.json`,
  generated by `scripts/heldout_wad_evaluation.py --generate-only` and shared by the main evaluation and the studies
- `diag_train_wad_batches/`: training-WAD replays for the train-vs-held-out gap of the Very Difficult variants,
  generated by `experiments/very_difficult/make_train_wad_diag_batches.py`

## Anonymization

Committed results must not contain absolute user paths, logins or node names. Run
`python scripts/anonymize_results.py results/<folder>` on new artifacts before committing them;
`comrad/tests/test_repository_anonymized.py` fails if a tracked file still contains such data.

## Relationship to the paper and raw runs

- the paper consumes copies of selected outputs under `paper/figure/`
- raw checkpoints and full training logs stay in `train_dir/` or on the HPC storage used for the runs; only derived
  artifacts are committed here
- a local `mode3_comrad_benchmark_20260503_134649/` copy of the benchmark checkpoints (used by
  `scripts/record_demo_one.sh` and `scripts/record_demo_all_checkpoints.sh`) is gitignored
