# `comrad/examples/`

Local debugging utilities. For runnable usage examples, see the top-level [`examples/`](../../examples) folder and the [quickstart](https://ttomilin.github.io/COMRAD/getting-started/quickstart/).

- `single_player.py`: small single-player interaction example
- `agent_run_env.py`: debug a multiplayer run with agents
- `you_run_env.py`: play as one of the agents with the keyboard
- `inspect_obs.py`: observation inspection
- `WandB_Scraper/`: legacy W&B plotting helpers
